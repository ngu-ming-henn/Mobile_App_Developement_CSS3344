# Lab 01: Flutter Basics — Student Profile Card

**CSS3344 Mobile Application Development**
**Student:** Ngu Ming Henn · **Student ID:** BCS24020001

A single-screen Flutter app that shows a student profile card with a profile photo, full name, student ID, and a personal life goal/quote.

## Widgets Used

`MaterialApp`, `Scaffold`, `AppBar`, `Center`, `Padding`, `Card`, `Column`, `CircleAvatar`, `Text`, `SizedBox`, `Divider`

## Project Structure

```
lib/main.dart            ← all app code
assets/image/myself.jpg  ← profile photo
test/widget_test.dart    ← widget test checking the student details render
```

## How to Run

```bash
flutter pub get
flutter run
```
